# **FECHA DE ENTREGA:** 29/10/2026

En esta versión debéis entregar un prototipo de las pantallas que tendrá vuestra aplicación. El objetivo es poder mostrar desde el inicio una primera propuesta a un cliente para que pueda revisarla y validar con vosotros qué necesita.

Antes de realizar esta tarea, debéis leer detenidamente el [documento de propuesta del proyecto individual](../enunciado_proyecto.md).

Para diseñar el prototipo podéis utilizar la siguiente herramienta:

![Prototipo](prototipo.png)

[Balsamiq Cloud](https://balsamiq.cloud/so9k30p/px3fwp0/r2278)

## Entrega

Para la entrega utilizar la plantilla de trabajos facilitada en Moodle.

El documento PDF debe incluir:

- El nombre y la descripción de la aplicación.
- Un diagrama de casos de uso únicamente del frontend (navegación).
- Un prototipo de las pantallas principales de la aplicación, adaptado a vuestra temática.
- Una breve explicación del recorrido entre las pantallas y de las acciones principales que podrá realizar el usuario.

Reunid todo el trabajo en un único archivo PDF. Para completar la entrega:

- Subid el PDF al repositorio Git del proyecto y adjuntadlo a la actividad correspondiente de Moodle.
- Incluid en Moodle la URL del repositorio y un vídeo breve en el que presentéis el prototipo y expliquéis el flujo principal.

## Criterios de finalización

- La propuesta tiene una temática y un público objetivo identificables.
- El prototipo representa las pantallas principales y permite entender cómo se relacionan.
- El diagrama representa acciones y navegación del frontend; no es necesario diseñar todavía la API ni la base de datos.
- La propuesta es coherente con el proyecto evolutivo descrito en el [enunciado general](../enunciado_proyecto.md).
